# Security policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability, credential, private source file, or customer data.

Use the repository's **Security > Report a vulnerability** form to send details privately. Include the affected version, reproduction steps, impact, and the smallest useful proof of concept. Reports are acknowledged on a best-effort basis.

ShipSentry Lite performs static pattern matching. Its output is not a security certification, and a clean report does not prove that an application is secure.
